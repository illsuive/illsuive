## 🚀 Featured Projects

### 🎬 Food-Reel
A comprehensive full-stack video-sharing web platform designed for food enthusiasts.
* **Stack:** MongoDB, Express.js, React, Node.js
* **Key Features:** Integrated seamless media optimization and cloud video management using ImageKit, paired with a secure Razorpay payment gateway subscription layer.

### 🌌 MoonMedia
A highly responsive, modern social media ecosystem focusing on security and real-time interaction.
* **Stack:** MERN Stack, JWT, Tailwind CSS
* **Key Features:** Secure JWT-based authentication workflows, custom middleware, two-factor authentication patterns, and optimized feed-rendering mechanics.

### 🗺️ MoonMoonTravller
An interactive tourist itinerary planner built for high-conversion lead generation.
* **Stack:** JavaScript, Tailwind CSS
* **Key Features:** Features custom fluid itinerary sliders, fully responsive layouts, and direct WhatsApp business integration for immediate user-to-agent lead routing.
